MUSAB OTP — تعليمات التشغيل والنشر

حساب الأدمن:
- اسم المستخدم الافتراضي: admin
- كلمة المرور: أنت تحددها في إعدادات الاستضافة عبر ADMIN_PASSWORD.
- لا توجد صفحة إنشاء حسابات عامة.
- لا ترفع الموقع إلى الإنترنت قبل تعيين كلمة مرور قوية وAPP_SECRET_KEY.

التشغيل محلياً:
1) ثبّت Python 3.11 أو أحدث.
2) نفّذ: pip install -r requirements.txt
3) عيّن متغيرات البيئة:
   ADMIN_USERNAME=admin
   ADMIN_PASSWORD=ضع_كلمة_مرور_قوية_هنا
   APP_SECRET_KEY=ضع_سراً_عشوائياً_طويلاً_هنا
4) نفّذ: python app.py
5) افتح الموقع على المنفذ 5000.

النشر:
- ارفع ملفات المشروع إلى استضافة تدعم Python/Flask.
- Build command: pip install -r requirements.txt
- Start command: gunicorn app:app
- أضف ADMIN_USERNAME وADMIN_PASSWORD وAPP_SECRET_KEY من إعدادات Environment Variables في الاستضافة.
- تأكد من وجود تخزين دائم لملف قاعدة البيانات musab_otp.sqlite3.
- استخدم HTTPS وCOOKIE_SECURE=1 عند النشر على HTTPS.

تنسيق الملفات:
- TXT: رقم واحد في كل سطر بصيغة دولية مثل +249123456789.
- CSV: أعمدة اختيارية phone وcountry.
- هذا الإصدار يرفع الأرقام ويصنفها تصنيفاً أولياً، وينزّل ملفات TXT.
- ربط مزوّد SMS غير مفعّل بعد؛ يحتاج اسم المزوّد ومفاتيح API الرسمية.
- أرقام الأرباح والمكافآت تجريبية وليست دفعات حقيقية. لا تُعتبر مستحقة إلا إذا أكدها مزوّد الخدمة.
- استخدم فقط أرقاماً تملكها أو لديك تصريح واضح لإدارتها.
